# Event size for the HiLumiLHC Run-4 TLA stream
Are you in the mood to figure out the event size for a potential Trigger-Level Analysis stream for the HiLumi LHC? Go through the folders in numerical order and follow the instructions in their respective READMEs *very* carefully. Give the jobs about 8-16 hours to run on the CERN computing grid (condor), but other than that you'll be there in no time.
